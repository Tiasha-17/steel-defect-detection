# wheel, so only it needs the +cpu-tagged build there. macOS has no +cpu
# variant (its wheels are CPU/MPS-only either way). torchvision never bundles
# CUDA (~8.6MB regardless of platform) and PyTorch's cpu index inconsistently
# publishes +cpu-tagged torchvision wheels per architecture (present for
# linux/x86_64, absent for linux/aarch64 e.g. Docker on Apple Silicon) -- so
# pin it plain and let pip pick whichever matching wheel is available.
